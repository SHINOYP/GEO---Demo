## Verification checklist before adding any reference

1. Look it up on Clarivate JCR (journal impact factor) or Scimago (SJR /
   quartile) -- do not trust a number from memory, a web search summary,
   or a third-party aggregator site (scijournal.org and similar are a
   starting point, not a source to cite from directly).
2. Confirm it is indexed (Scopus/Web of Science) if the department
   requires indexed journals.
3. Record the exact impact factor, year, and source (JCR or Scimago) next
   to the reference in the final report's bibliography, so it's
   defensible if a panelist asks.
4. Prefer the most recent available impact factor; note the year used.
