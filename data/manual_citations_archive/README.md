# Archived collection worksheets

These are the original, as-filled Perplexity citation worksheets from the
two data-collection passes (100 queries, then 100 more). They are kept only
as a provenance record of how the data was actually collected.

**They are not used by anything.** The canonical, current input to
`pipeline/import_manual_citations.py` is `data/manual_citations_full.txt`
(the concatenation of these two files, Q01–Q200) — see `docs/DATA_CARD.md`.

- `batch1_q01-q100.txt` — first collection pass (100 queries).
- `batch2_q101-q200.txt` — second pass, scaling to the full 200 queries.
