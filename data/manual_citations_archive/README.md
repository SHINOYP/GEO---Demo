# Archived collection worksheets

These are the original, as-filled Perplexity citation worksheets from the
three data-collection passes (100 queries, then 100 more, then 100 more
again). They are kept only as a provenance record of how the data was
actually collected.

**They are not used by anything.** The canonical, current input to
`pipeline/import_manual_citations.py` is `data/manual_citations_full.txt`
(the concatenation of these three files, Q01–Q300) — see `docs/DATA_CARD.md`.

- `batch1_q01-q100.txt` — first collection pass (100 queries).
- `batch2_q101-q200.txt` — second pass, scaling to 200 queries.
- `batch3_q201-q300.txt` — third pass, scaling to the full 300 queries.
